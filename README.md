# MUR IDE — Автономная миссия АНПА с YOLOv8

Программа для автономного необитаемого подводного аппарата (АНПА) в симуляторе MUR IDE. Выполняет поиск объекта, прицеливание и маркировку торпедой с использованием нейросетевого детектора YOLOv8.

## Возможности

- Детекция объектов через YOLOv8 (предобученная модель)
- Автоматическое прицеливание по центроиду объекта
- Стабилизация глубины (П-регулятор)
- Обход препятствий при столкновении со стеной

## Быстрый старт

1. Установите MUR IDE с [murproject.com](https://murproject.com/#muride)
2. Установите зависимости:
   ```
   python -m pip install ultralytics opencv-python numpy
   ```
3. Откройте `mission.py` в MUR IDE и нажмите F5

## Настройка параметров

| Параметр | Значение | Описание |
|----------|----------|----------|
| `BASE_SPEED` | 45 | Скорость движения |
| `TARGET_DEPTH` | 2.5 | Глубина (м) |
| `CONF_THRESHOLD` | 0.5 | Порог уверенности YOLO |

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Ultralytics не найдена | `python -m pip install ultralytics` |
| Объект не видит | Снизьте `CONF_THRESHOLD` до 0.3 |
| Выстрел не работает | Снизьте порог `area > 1000` |
